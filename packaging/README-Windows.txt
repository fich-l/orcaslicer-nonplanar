OrcaSlicer Nonplanar v@VERSION@ (test release, Windows)

1. Unzip this folder anywhere (for example to your Documents folder).
2. Start orca-slicer.exe in the folder "OrcaSlicer Nonplanar".
3. The app is not signed. If Windows shows "Windows protected your PC",
   click "More info", then "Run anyway".
4. The app has its own settings folder (%APPDATA%\OrcaSlicerNonplanar).
   It does not change an installed OrcaSlicer, its settings, file
   associations or orcaslicer:// links. Both can be used side by side.
   Nonplanar layers are on by default (12 degrees, 5 mm).
5. Bambu Lab A1 mini: import "0.20mm Nonplanar @BBL A1M.json" with
   File > Import > Import Configs.

Check the preview before printing. Details and issue reports:
https://github.com/fich-l/orcaslicer-nonplanar
